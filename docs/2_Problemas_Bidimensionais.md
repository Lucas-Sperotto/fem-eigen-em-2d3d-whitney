# 2. Problemas Bidimensionais

Neste arquivo, a parte mais formativa da Seção 2 é a formulação escalar de 2.1. É aqui que o leitor deve aprender, com calma, o gesto fundamental do método: partir de uma equação diferencial contínua, construir sua forma fraca, discretizá-la com funções de base simples e então reconhecer, dentro das matrizes, a física do problema.

## Como a seção 2 se organiza

- [2.1 Guias de Onda Homogêneos](2.1_Guias%20de%20Onda%20Homogêneos.md): formulação escalar com elementos nodais triangulares.
- [2.2 Guias de Onda Não Homogêneos](2.2_Guia_Nao_Homogeneo.md): introdução à formulação vetorial com elementos de aresta.
- [2.2.1 Campos Vetoriais Transversais](2.2.1_Guia%20de%20Onda%20Campos%20Vetoriais.md): caso homogêneo vetorial em 2D.
- [2.2.2 Três Componentes](2.2.2_Guias_de_Onda_Nao_Homogeneos_Tres_Componentes.md): formulação mista com componente longitudinal.
- [2.2.3 Determinação do Número de Onda](2.2.3_Determinação%20do%20número%20de%20onda.md): problema espectral para $k_0$ com $\beta$ fixado.
- [2.2.4 Características de Dispersão](2.2.4_Caracteristicas_de_Dispersao_de_Guias_de_Onda.md): problema espectral para $\beta$ com $k_0$ fixado.
