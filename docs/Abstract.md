## Abstract

O método dos elementos finitos (FEM) tem sido uma ferramenta muito poderosa para resolver muitos problemas complexos em eletromagnetismo. O objetivo da pesquisa atual nos :contentReference[oaicite:0]{index=0} é desenvolver um método FEM baseado na abordagem dos momentos para problemas tridimensionais de espalhamento/radiação para objetos com forma arbitrária e preenchidos com materiais complexos.

Como um primeiro passo em direção a esse objetivo, realiza-se um exercício para estabelecer o poder do FEM, por meio de problemas de contorno fechados. Este artigo demonstra o desenvolvimento de ferramentas FEM para problemas bidimensionais e tridimensionais em eletromagnetismo.

Na Seção 2, tanto elementos finitos escalares quanto vetoriais foram utilizados para vários problemas de guias de onda para demonstrar a flexibilidade do FEM. Na Seção 3, o método de elementos finitos vetoriais foi estendido para problemas tridimensionais de autovalores.
