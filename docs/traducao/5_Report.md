## 13. Resumo

O método dos elementos finitos (FEM) tem sido uma ferramenta muito poderosa para resolver muitos problemas complexos em eletromagnetismo. O objetivo deste relatório é desenvolver um método FEM combinado que demonstre uma abordagem sistemática para tratar problemas de autovalor relacionados a guias de onda arbitrários preenchidos com dielétricos. Como primeiro passo para atingir esse objetivo, um exercício é realizado para estabelecer o poder do FEM por meio de problemas clássicos com soluções conhecidas. Este relatório demonstra o desenvolvimento do FEM para problemas de autovalor bidimensionais e tridimensionais em eletromagnetismo. Nas Seções 1 e 2, tanto elementos escalares quanto vetoriais são utilizados para diversos problemas de guias de onda, demonstrando a flexibilidade do FEM. Na Seção 3, o método dos elementos finitos vetoriais é estendido para problemas de autovalor tridimensionais.
