## 📌 Lista de Símbolos

### 🔷 Vetores e Quantidades Gerais

| Símbolo | Descrição |
|--------|----------|
| $\mathbf{A}, \mathbf{B}$ | Vetores genéricos utilizados em identidades vetoriais |
| $f$ | Escalar genérico utilizado em identidades vetoriais |
| $\hat{x}, \hat{y}, \hat{z}$ | Vetores unitários nas direções cartesianas |
| $\hat{n}$ | Vetor normal unitário à superfície |

---

### 🔷 Campos Eletromagnéticos

| Símbolo | Descrição |
|--------|----------|
| $\mathbf{E}$ | Campo elétrico: $\mathbf{E} = E_x \hat{x} + E_y \hat{y} + E_z \hat{z}$ |
| $\mathbf{E}_t$ | Campo elétrico transversal: $E_x \hat{x} + E_y \hat{y}$ |
| $E_x, E_y, E_z$ | Componentes do campo elétrico |
| $\mathbf{H}$ | Campo magnético: $\mathbf{H} = H_x \hat{x} + H_y \hat{y} + H_z \hat{z}$ |
| $\mathbf{H}_t$ | Campo magnético transversal |
| $H_x, H_y, H_z$ | Componentes do campo magnético |

---

### 🔷 Parâmetros Físicos

| Símbolo | Descrição |
|--------|----------|
| $\varepsilon_r$ | Permissividade relativa |
| $\mu_r$ | Permeabilidade relativa |
| $\lambda_0$ | Comprimento de onda no espaço livre |
| $k_0$ | Número de onda no espaço livre: $k_0 = \frac{2\pi}{\lambda_0}$ |
| $k_c$ | Número de onda de corte |
| $\beta$ | Constante de propagação |

---

### 🔷 Operadores Diferenciais

| Símbolo | Descrição |
|--------|----------|
| $\nabla$ | Operador gradiente tridimensional |
| $\nabla_t$ | Gradiente transversal (plano XY) |
| $\nabla \times$ | Operador rotacional (curl) |
| $\nabla \cdot$ | Operador divergente |

---

### 🔷 Elementos Finitos — Geometria

| Símbolo | Descrição |
|--------|----------|
| $V$ | Volume do elemento tetraédrico |
| $\Omega_e$ | Domínio do elemento tetraédrico |
| $L_m$ | Comprimento da aresta $m$ do tetraedro, $m = 1,2,\dots,6$ |
| $L_{tm}$ | Comprimento da aresta $m$ do triângulo |
| $x_i, y_i, z_i$ | Coordenadas dos nós do elemento |
| $\bar{x}_{tet}, \bar{y}_{tet}, \bar{z}_{tet}$ | Centroide do tetraedro |
| $\bar{x}_{tri}, \bar{y}_{tri}$ | Centroide do triângulo |

---

### 🔷 Funções de Base (Elementos de Aresta)

| Símbolo | Descrição |
|--------|----------|
| $\mathbf{W}_m$ | Função de base vetorial de aresta (edge element) associada à aresta $m$ |
| $\mathbf{W}_{tm}$ | Função de base vetorial para elemento triangular |
| $e_m$ | Coeficiente desconhecido associado à aresta $m$ do tetraedro |
| $e_{tm}$ | Coeficiente em elemento triangular |
| $[e]$ | Vetor global de incógnitas (graus de liberdade nas arestas) |

---

### 🔷 Funções de Forma

| Símbolo | Descrição |
|--------|----------|
| $\alpha_i$ | Função de forma linear de primeira ordem (triângulo) |
| $\alpha_{tm}$ | Função de forma linear de tetraedro |
| $\psi$ | Função escalar potencial (TE/TM) |
| $\psi_i$ | Valores nodais da função $\psi$ |

---

### 🔷 Coeficientes Geométricos

| Símbolo | Descrição |
|--------|----------|
| $A_m$ | Coeficiente associado à função de base |
| $A_{xm}, A_{ym}, A_{zm}$ | Componentes do vetor $A_m$ |
| $B_m$ | Coeficiente associado à geometria do elemento |
| $B_{xm}, B_{ym}, B_{zm}$ | Componentes do vetor $B_m$ |
| $C_m$ | Coeficiente geométrico |
| $C_{xm}, C_{ym}, C_{zm}$ | Componentes do vetor $C_m$ |
| $D_m$ | Coeficiente adicional da formulação |

---

### 🔷 Matrizes FEM

| Símbolo | Descrição |
|--------|----------|
| $[S]$ | Matriz global de rigidez (curl-curl) |
| $[T]$ | Matriz global de massa |
| $[S_e]$ | Matriz de rigidez do elemento |
| $[T_e]$ | Matriz de massa do elemento |
| $[S_{tt}], [S_{zz}], [S_{tz}]$ | Submatrizes globais |
| $[T_{tt}], [T_{zz}], [T_{tz}]$ | Submatrizes globais |

---

### 🔷 Problema de Autovalor

|--------|----------|

| $[S][e] = k_0^2 [T][e]$ | Equação matricial do problema FEM |
